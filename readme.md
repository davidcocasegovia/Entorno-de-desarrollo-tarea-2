# StudyPlan 📚

> Aplicación web y móvil diseñada para estudiantes con el fin de organizar tareas, exámenes y sesiones de estudio de manera eficiente.

## 📌 Descripción del Proyecto
**StudyPlan** surge como respuesta a la desorganización académica habitual en estudiantes, ayudando a reducir el olvido de fechas importantes y facilitando la planificación del estudio mediante calendarios centralizados y recordatorios automatizados.

Este proyecto forma parte de la **Tarea 2 del Módulo de Entorno de Desarrollo (MEDAC)**, enfocada en el reconocimiento de elementos en el desarrollo de un programa informático, el análisis de requisitos y la selección de metodologías de desarrollo.

---

## 🚀 Características Principales

### ⚙️ Requisitos Funcionales
* **RF1 - Registro de usuario:** Permite al estudiante crear una cuenta personal.
* **RF2 - Gestión de tareas:** Crear, consultar, modificar y eliminar tareas.
* **RF3 - Gestión de fechas:** Registro de exámenes y fechas de entrega.
* **RF4 - Calendario:** Visualización de tareas y eventos organizados por fechas.
* **RF5 - Recordatorios:** Envío de avisos sobre tareas y exámenes próximos.
* **RF6 - Estado de tareas:** Marcar tareas como pendientes o completadas.

### 🛡️ Requisitos No Funcionales
* **Rendimiento:** Respuestas rápidas y fluidas ante las acciones habituales.
* **Seguridad:** Protección estricta de datos personales y credenciales.
* **Usabilidad:** Interfaz clara, sencilla e intuitiva para estudiantes de cualquier nivel.
* **Compatibilidad:** Accesible tanto desde dispositivos móviles (Android/iOS) como desde navegadores web.
* **Disponibilidad:** Mecanismos de recuperación para evitar la pérdida de información.

---

## 🔄 Metodología de Desarrollo
El proyecto está planteado bajo una **metodología ágil**, concretamente **Scrum**. Esto permite:
* Trabajar mediante *sprints* (ciclos cortos, por ejemplo, de 15 días).
* Desarrollar el producto de forma progresiva, incorporando funcionalidades básicas al inicio y ampliándolas iterativamente.
* Adaptarse con flexibilidad a los cambios en los requisitos del cliente o usuario.
